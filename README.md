# 2025 Unity Brol Game Studio - Core (BGS Core)

Is not Bogosse Core but it's a core system to helpfull to develop your games.
- Script Manager system to centralise
- Helpfull to make save system in your game
- Centralise Data from Scriptable Object

## System Requirements
Developed and testing with **Unity 6**. Please create a [pull request](https://github.com/thewasmans/2025-unity-bol-game-studio/pulls) if something wrong with other versions

## Installation
1. You can install from the Package Manager and insert the following url
```
https://github.com/thewasmans/2025-unity-bol-game-studio.git#bgs-core
```
<img src="https://github.com/user-attachments/assets/5c53f3fd-c87c-4732-bab8-a3302e05d04e" width="400" height="400">

2. You can also install via git url by adding this entry in your **manifest.json**
```
"com.brol-game-studio.core": "https://github.com/thewasmans/2025-unity-bol-game-studio.git#bgs-core"
```
